# Code of Conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):

- Be respectful, constructive, and professional.
- Focus on what is best for the openEHR community.
- No harassment, personal attacks, or disrespectful behavior of any kind.

Unacceptable behavior can be reported to the repository maintainers; reports are handled promptly and confidentially. Maintainers may remove contributions or contributors that violate this code.
